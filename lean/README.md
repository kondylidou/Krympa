# Lean proofs

Lean project used to check Krympa proofs. From this directory:

```bash
lake env lean Proof/<file>.lean
```

No output and exit status 0 means the proof is accepted.

## Files in `Proof/`

| File | Theorem | Notes |
|---|---|---|
| `proof.lean` | Equation650 ⇒ Equation448 | Krympa proof |
| `ts_proof.lean` | Equation650 ⇒ Equation448 | `--term-size` proof, 19 steps |
| `ts_proof_16.lean` | Equation650 ⇒ Equation448 | `--term-size --refine` proof, 16 steps |
| `secondproof.lean` | Equation947 ⇒ Equation3897 | Krympa proof |
| `direct_proof_15.lean` | Equation650 ⇒ Equation448 | `--direct` proof after step removal, 15 steps |

The first four use `nth_rw` and need Mathlib. `direct_proof_15.lean` was
generated by `./krympa lean direct_proof_15.out` and needs only core Lean.
`vampire_proof_62.out` is the saved 62-step Vampire proof that both the 16-
and the 15-step proof start from. Vampire on macOS gives an 82-step proof
instead, so to reproduce the 15 steps, start from this file:

```bash
./benchmarking_binary generate benchmarks/Proofs11.lean
mkdir -p output
cp lean/Proof/vampire_proof_62.out output/vampire_proof_Equation650_implies_Equation448.out
./krympa direct benchmarks/input11/Equation650_implies_Equation448.p
./krympa compress output/proof_Equation650_implies_Equation448.out
./krympa lean output/proof_Equation650_implies_Equation448_compressed.out
```

Run these from the Krympa folder.

## Generated files

`./krympa lean <proof.out>` or a run with `--lean` writes
`Proof/<name>.lean` here and checks it. A generated file needs only core Lean:
every step is an explicit proof term, so Lean checks it in a few seconds
without searching. See the main `README.md`.
